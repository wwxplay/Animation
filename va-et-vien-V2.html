⚡ Circuit électrique : le va-et-vient

Un va-et-vient permet de commander une même lampe depuis deux endroits. Cliquez sur les points noirs des interrupteurs (ou sur les boutons) pour changer leur position.

Principe : la lampe s'allume uniquement lorsque les deux interrupteurs sont dans la même position (1-1 ou 2-2). Dans le cas contraire, le courant est interrompu par l'un des deux interrupteurs. Le courant suit le chemin : Phase → interrupteur A → voyageur → interrupteur B → lampe → neutre.
